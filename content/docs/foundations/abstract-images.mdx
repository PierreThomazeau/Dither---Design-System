Each image is a composition of soft, blurred colour bands and glows, painted from the chart, brand and status tokens, so light and dark follow. It is then drawn through the grid: no photo, no file to load, and it drifts slowly (still under reduced motion, paused off-screen). Download any of them as a 1600 × 1200 PNG.

## Installation

<InstallCommand name="dither-image" />

## Usage

```tsx
import { DitherImage } from "@/lib/dither-image";

<DitherImage preset="ember" className="aspect-[4/3] rounded-surface" />
<DitherImage preset="lagoon" mode="pixel" ground="light" className="h-64" />
```

It fills its box: give it a size or an aspect ratio.

## Two renderings

- **Dots** (default): one 2px dot per 4px cell, coloured by the image; a Bayer 4 × 4 threshold on its brightness thins dark areas to nothing, so colour packs where the image is bright. Same dot and grid as the organic tile.
- **Pixel**: contiguous 2px pixels (each one system dot), the same threshold, colours posterised (six levels per channel, ordered dither): a crisp print.

`ground="dark"` (default) lays the dots on the darkest neutral of the theme; `ground="light"` on the lightest, where colour reads as ink.

## Your own image

Pass `src` instead of a preset (same origin, or a CORS-enabled URL). The image is fitted like `object-fit: cover`.

<DitherImageSourceDemo />

```tsx
<DitherImage src="/hero.jpg" mode="dots" className="aspect-video" />
```

## Export

`renderDitherImage(element, width, height, options)` returns a canvas with a still, to save or upload.

```tsx
const canvas = await renderDitherImage(document.body, 1600, 1200, { preset: "dusk", mode: "pixel" });
canvas.toBlob((blob) => save(blob));
```
