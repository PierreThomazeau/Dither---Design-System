## Organic shapes

Surfaces (heroes, cards, empty states, AI headers, footer) use the **organic** texture: the same pixel grid,
but each cell's density comes from a noise field, so the dots gather in masses, fray at the edges and leave
holes, and the densest areas get bigger dots (2 → 4px). It drifts slowly, the pointer clears a soft hole,
it pauses off-screen and stays still under reduced motion.

<ComponentPreview name="dither-organic" />

| Shape | Look | Used by |
|---|---|---|
| `cloud` | Soft masses and holes, slow warp | Card `dither`, footer, AI glow |
| `scatter` | Dense on top, ragged edge, loose grain below | Landing hero, Stat Card `gradient`, onboarding |
| `halo` | A granular frame around the content, the centre always empty | Empty `dither` |
| `flow` | Warped bands, like contour lines | Chart and showcase backdrops |

```tsx
<div className="relative h-40 overflow-hidden rounded-surface border">
  <DitherFill shape="scatter" />
</div>
```

`scale` (higher = smaller clumps) and `seed` vary neighbouring panels; `tint` paints the dots with a
gradient of custom properties (`{ stops: ["transparent", "--brand", "--chart-3"], direction: "to-r" }`).

## Tile variants

Data marks (remaining capacity, chart tracks, legends, skeletons) keep the regular tile: it reads as a
value, where noise would read as data.

| Variant | Spec |
|---|---|
| `regular` | 2px squares on a 6px grid, odd rows offset by 3px |
| `fine` | 1.5px squares on a 4px grid, odd rows offset by 2px |
| `bayer` | 4×4 ordered dither, 4px cells, threshold 0.32 |
| `gradient` | 4×4 ordered dither, density fading 0.68 → 0.06 top to bottom |

The dots use `--dither-color`, which defaults to `--border-strong`, so the texture follows light and dark.

## Props

### DitherPattern

An SVG `<pattern>` to put in the `<defs>` of any SVG (charts, tracks, forecast bands).

<TypeTable
  type={{
    id: { type: "string", description: "Referenced by fill=\"url(#id)\". Unique on the page.", required: true },
    variant: { type: '"regular" | "fine" | "bayer" | "gradient"', default: '"regular"' },
    gradientHeight: { type: "number", description: "Height of the gradient tile in px.", default: "256" },
  }}
/>

### DitherFill

Fills its positioned parent: the organic canvas when `shape` is set, otherwise the tile as SVG
(or the repelling dot field with `interactive`).

<TypeTable
  type={{

    interactive: { type: "boolean", default: "false", description: "Tile only: dots pushed away by the pointer." },
  }}
/>

### CSS utility

`bg-dither`, `bg-dither-fine`, `bg-dither-bayer` and `bg-dither-gradient` apply the texture as a mask over
`--dither-color`. A mask also clips children, so put the utility on its own layer:

```tsx
<div className="relative h-24 rounded-surface border">
  <span className="bg-dither-gradient absolute inset-0 rounded-[inherit]" />
  <p className="relative">No reports yet</p>
</div>
```

  </div>
</Preview>

Change the colour per element: `[--dither-color:var(--chart-1)]`.
