Two sets, one rule: **static by default, animated where the gesture means something** (a bell rings, a download lands, a lock resists).

- **Hugeicons** (`@hugeicons/react`, stroke 1.5, 16px) for navigation, labels and everything that should stay still. Use them through `Icon` from `lib/icon`.
- **Dither Icons** ([@unlocalhosted/dither-icons](https://github.com/vijayksingh/dither-icons), MIT) for actions and feedback, through `AnimatedIcon` from `lib/animated-icon`.

## Installation

```bash
npx shadcn add @dither/animated-icon
```

This installs `lib/animated-icon.tsx` and the `@unlocalhosted/dither-icons` package.

## Usage

```tsx
import { AnimatedIcon } from "@/lib/animated-icon";

<Button>
  <AnimatedIcon name="download" />
  Download report
</Button>
```

- **The whole control plays the icon.** `Button`, `PeriodButton`, nav links, `Empty` and the Side Panel trigger carry `di-trigger`, so hovering, focusing or tapping anywhere on them plays the gesture once. Add `di-trigger` to any other interactive parent.
- **Three materials.** `line` (default up to 24px, a stroke close to Hugeicons'), `solid`, and `dither` (default from 32px): the outline over the silhouette filled with Dither's organic grain, the same 1.25 → 2px dots as the rest of the system. The package's own dither material (a 0.5px grain) is not used.
- **Colour** comes from `currentColor`; **reduced motion** stops every gesture; without `title` an icon is decorative, so name icon-only buttons with `aria-label`.
- **Gestures stay meaningful.** Never use an animated icon as proof that something worked: keep the real loading, success and error states.
- **Weight.** The package ships its whole catalogue in one module (no per-icon splitting), so prefer it in client components that already need interactivity.
