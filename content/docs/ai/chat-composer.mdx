## Usage

```tsx
import { ChatComposer } from "@/components/blocks/chat-composer";

<ChatComposer onSubmit={(message, tools) => send(message, tools)} />
```

## Guidelines

- Enter sends, Shift + Enter adds a line; show Stop while answering.
- Put the [Companion](/docs/ai/companion) in the conversation (`CompanionLayer`), not on the composer.
- Use `onValueChange` to set the companion to listening while people type.
