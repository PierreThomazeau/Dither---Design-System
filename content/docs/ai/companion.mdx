## Usage

Wrap the conversation in `CompanionLayer` and drop a `CompanionAnchor` where it should stand: in the middle of an empty chat, then on top of the answer being written. The most recent anchor wins and the companion glides there (it is never remounted). Drive it with the status of your AI call.

```tsx
import { ChatComposer } from "@/components/blocks/chat-composer";
import { CompanionAnchor, CompanionLayer } from "@/components/blocks/companion";

<CompanionLayer companion={{ status }}>
  {messages.length === 0 ? (
    <CompanionAnchor size={128} />
  ) : (
    messages.map((m, i) => (
      <Message key={m.id} from={m.from}>
        {i === lastAnswer ? <CompanionAnchor size={64} /> : null}
        <Bubble>{m.text}</Bubble>
      </Message>
    ))
  )}
</CompanionLayer>
<ChatComposer onValueChange={(v) => setStatus(v ? "listening" : "idle")} onSubmit={ask} />
```

`Companion` alone renders it at a fixed `size`.

## How it reacts

| Status | Face | Body |
| --- | --- | --- |
| `idle` | Happy, faces you, eyes follow the pointer | Satin chrome tinted `background-muted` |
| `listening` | Looks down at what you type | Tinted `positive` |
| `thinking` | Looks up, thought dots | Tinted `brand` |
| `thinking` after `slowAfter` s | Bored: heavy lids, sighs | Tinted `destructive` |
| `thinking` after 2.2 × `slowAfter` | Lazy: slumped, yawns | More `destructive` |
| `responding` | Talks | Satin chrome |
| `done` | Proud, bounces, "Done" on the screen | One multicolour band sweeps up, then satin chrome |
| `error` | Sad | Tinted `destructive` |

Tints are token colours mixed into the background colour, read live from CSS, so light and dark follow.

`mood` forces an expression: `happy`, `proud`, `excited`, `impatient`, `sleepy`, `resting`, `bored`, `disdainful`, `lazy`, `thinking`, `sad`. Every expression is a set of numbers that glide to the target, so changes are always smooth.

The face is drawn crisp, shrunk to 80 × 80 dots and dithered in 1 bit (Bayer 4 × 4) on the LED screen. three.js is loaded on demand, rendering pauses off-screen and in hidden tabs, and everything is disposed on unmount. Under reduced motion only the face moves.
