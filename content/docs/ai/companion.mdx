## Usage

Put it on a [Chat Composer](/docs/ai/chat-composer) with `companion`, and drive it with the status of your AI call.

```tsx
import { ChatComposer } from "@/components/blocks/chat-composer";
import { Companion } from "@/components/blocks/companion";

<ChatComposer
  busy={status === "thinking" || status === "responding"}
  onValueChange={(v) => setStatus(v ? "listening" : "idle")}
  onSubmit={ask}
  companion={<Companion status={status} />}
/>
```

## How it reacts

| Status | Face | Chrome |
| --- | --- | --- |
| `idle` | Happy, eyes follow the pointer | Polished chrome |
| `listening` | Looks down at what you type | Mint |
| `thinking` | Looks up, thought dots | Indigo |
| `thinking` after `slowAfter` s | Bored: heavy lids, sighs | Red |
| `thinking` after 2.2 × `slowAfter` | Lazy: slumped, yawns | Deep red |
| `responding` | Talks | Sky |
| `done` | Proud, bounces, "Done" on the screen | One multicolour sweep, then chrome |
| `error` | Sad | Orange |

`mood` forces an expression: `happy`, `proud`, `excited`, `impatient`, `sleepy`, `resting`, `bored`, `disdainful`, `lazy`, `thinking`, `sad`. Every expression is a set of numbers that glide to the target, so changes are always smooth.

The face is drawn crisp, shrunk to 80 × 80 dots and dithered in 1 bit (Bayer 4 × 4) on the LED screen. three.js is loaded on demand, rendering pauses off-screen and in hidden tabs, and everything is disposed on unmount. Under reduced motion only the face moves.
