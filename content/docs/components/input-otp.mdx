## Usage

```tsx
import { InputOTP, InputOTPGroup, InputOTPSlot } from "@/components/ui/input-otp";

<InputOTP maxLength={6} onComplete={verify}>
  <InputOTPGroup>
    {[0, 1, 2, 3, 4, 5].map((i) => <InputOTPSlot key={i} index={i} />)}
  </InputOTPGroup>
</InputOTP>
```

## Guidelines

- Paste works, and phones suggest codes received by SMS (one-time-code autocomplete).
- Verify on `onComplete`; on failure, clear and show the error under the boxes.
- Give it an `aria-label` (for example: Verification code).
