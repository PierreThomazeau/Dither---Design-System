## Usage

```tsx
import { Button } from "@/components/ui/button";

<Button>Save changes</Button>
<Button variant="outline" size="sm">Cancel</Button>
```

## Guidelines

- **One primary button per view**: the main action. Others are outline, secondary or ghost.
- Labels are verbs ("Save changes", "Send invoice"), not "OK" or "Submit".
- Use `loading` while the action runs, then a success moment (toast, or the sweep in the button).
- Icon-only buttons need an `aria-label`. Destructive actions use `variant="destructive"` and offer Undo.
