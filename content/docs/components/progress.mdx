## Usage

```tsx
import { Progress } from "@/components/ui/progress";

<Progress value={64} aria-label="Storage" />
<Progress variant="density" value={42} aria-label="Uploading" />
<Progress aria-label="Syncing" />  {/* indeterminate */}
```

## Guidelines

- **bar** for quantities (storage, quota): the remaining part is dither, as everywhere in Dither.
- **density** for work in progress (uploads, imports): the dots light up as it advances. It is the dither rule "density = progress".
- No value = indeterminate: the dither drifts.
- Always give an `aria-label` (or `aria-labelledby`).
