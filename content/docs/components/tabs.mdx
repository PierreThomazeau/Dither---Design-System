## Usage

```tsx
import { Tabs, TabsContent, TabsList, TabsTrigger } from "@/components/ui/tabs";

<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="reports">Reports</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">…</TabsContent>
</Tabs>
```

## Guidelines

- **Use** to switch between views of the same thing; not for steps (use a stepper) or navigation between pages.
- Keep labels short (1–2 words); the active tab is never the only place a state shows.
- Arrow keys move between tabs. Tabs used only as a switch (no TabsContent) drop their dangling `aria-controls`.
