## Usage

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select";

<Select>
  <SelectTrigger aria-label="Period">
    <SelectValue placeholder="Select a period" />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="30d">Last 30 days</SelectItem>
  </SelectContent>
</Select>
```

## Guidelines

- **Use** for 5 to ~10 options; fewer: Radio Group; more or searchable: [Combobox](/docs/components/combobox).
- Pick a sensible default when there is one; otherwise a placeholder that says what to choose.
- Arrow keys and type-ahead work; the list never covers its own trigger.
