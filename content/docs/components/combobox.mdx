## Usage

```tsx
import { Combobox } from "@/components/ui/combobox";

<Combobox options={squads} placeholder="Assign a squad" onValueChange={setSquad} />
<Combobox multiple options={squads} onValueChange={setSquads} />
```

## Guidelines

- **Use** instead of Select past ~10 options, or when people know what they are looking for.
- Multiple: chips in the trigger, each removable; the list stays open between picks.
- Type to filter, arrows to move, Enter to pick, Escape to close (the Side Panel stays open).
