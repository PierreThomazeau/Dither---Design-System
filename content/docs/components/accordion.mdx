## Usage

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@/components/ui/accordion";

<Accordion type="single" collapsible>
  <AccordionItem value="billing">
    <AccordionTrigger>How does billing work?</AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Guidelines

- **Use** for secondary content people scan by heading (FAQ, advanced settings).
- **Don't** hide what everyone needs: primary content stays visible.
- Triggers are real buttons in headings; Up / Down move between them, Home / End jump to the first and last.
