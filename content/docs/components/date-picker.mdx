## Usage

```tsx
import { DatePicker } from "@/components/ui/date-picker";
import { Calendar } from "@/components/ui/calendar";

<DatePicker value={due} onValueChange={setDue} />
<DatePicker mode="range" value={period} onValueChange={setPeriod} />
<Calendar mode="single" selected={day} onSelect={setDay} />
```

## Guidelines

- Range shows two months; the selected span is a muted band between two primary ends.
- Dates are formatted with `Intl` (pass `locale` to force one).
- The calendar is fully keyboard driven (arrows, Page Up / Down for months, Home / End for weeks).
