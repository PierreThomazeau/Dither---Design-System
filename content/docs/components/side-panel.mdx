## Usage

```tsx
import {
  SidePanel, SidePanelContent, SidePanelFooter, SidePanelHeader,
  SidePanelInset, SidePanelLayout, SidePanelProvider, SidePanelTrigger,
} from "@/components/ui/side-panel";

<SidePanelProvider>
  <SidePanelLayout>
    <SidePanelInset>
      {/* page content */}
      <SidePanelTrigger asChild><Button variant="outline">Details</Button></SidePanelTrigger>
    </SidePanelInset>
    <SidePanel label="Invoice details">
      <SidePanelHeader title="INV-2041" description="Lumen Finance" />
      <SidePanelContent>…</SidePanelContent>
      <SidePanelFooter><Button>Download</Button></SidePanelFooter>
    </SidePanel>
  </SidePanelLayout>
</SidePanelProvider>
```

- **It pushes, it never floats.** The panel owns a column whose width animates from 0, so the content reflows next to it. Use a [Sheet](/docs/components/sheet) when the panel must sit over the page.
- **A card on a darker ground.** Full height, `rounded-surface`, `background-muted` (surface in dark mode), 8px from the edges.
- **Motion rule.** Opens in 200ms ease-out, closes in 100ms ease-in (see [Motion](/docs/foundations/motion)). Escape closes it; when closed it is `inert`.
