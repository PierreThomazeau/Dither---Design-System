## Usage

```tsx
import { DataTable, DataTableSortHeader } from "@/components/ui/data-table";

<DataTable columns={columns} data={invoices} selectable searchPlaceholder="Search invoices"
  toolbar={(table) => <Button onClick={() => deleteSelected(table)}>Delete selected</Button>} />
```

## Guidelines

- Numbers, IDs and dates in mono, right-aligned when they are compared.
- Bulk delete with `toast.undo`, not a confirmation dialog.
- Sortable headers are buttons and the column gets `aria-sort`.
