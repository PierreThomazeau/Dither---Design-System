## Usage

```tsx
import { Field, FieldControl, FieldLabel } from "@/components/ui/field";

<Field description="We send invoices here." error={errors.email}>
  <FieldLabel>Work email</FieldLabel>
  <FieldControl><Input type="email" /></FieldControl>
</Field>
```

## Guidelines

- **Show errors next to the field**, in a sentence that says how to fix it. Never in a toast.
- Validate on submit, then live once a field has an error.
- `FieldControl` gives the control its id, `aria-invalid` and `aria-describedby` (description and error).
