## Usage

```tsx
import { Slider } from "@/components/ui/slider";

<Slider defaultValue={[40]} aria-label="Volume" />
<Slider defaultValue={[20, 70]} step={5} />  {/* range */}
```

## Guidelines

- **Use** when the exact number matters less than the feel (volume, zoom, price range); show the value next to the label.
- **Don't** use it for precise entry: pair it with an Input, or use the Input alone.
- Arrow keys move by `step`, Page Up / Down by 10 steps, Home / End to the ends.
- Give a single thumb an `aria-label`; range thumbs are labelled Minimum and Maximum.
