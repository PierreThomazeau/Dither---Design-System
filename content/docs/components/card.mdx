## Usage

```tsx
import { Card, CardContent, CardDescription, CardHeader, CardInset, CardTitle } from "@/components/ui/card";

<Card>
  <CardHeader>
    <CardTitle>Revenue</CardTitle>
    <CardDescription>Last 30 days</CardDescription>
  </CardHeader>
  <CardContent>…</CardContent>
</Card>

<Card variant="inset" dither>
  <CardHeader><CardTitle>Northwind Studio</CardTitle></CardHeader>
  <CardInset>…</CardInset>
</Card>
```

`CardHeader`, `CardTitle`, `CardDescription`, `CardAction` (top-right slot), `CardContent`, `CardFooter`, `CardInset` (inner panel of an inset card), `CardImage` (full-bleed media).

## Guidelines

- Group one subject per card; a card is not a layout grid.
- Inset (grammar 2) for a header or footer that frames a panel; `dither` for empty or remaining parts only.
- Make the whole card clickable only when it has a single action, and keep a real link or button inside.
